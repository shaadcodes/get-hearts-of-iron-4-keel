## 🧠 Choosing Which Modules To Actually Use

More modules is not better. The useful question is which ones fit how you play.

**Start from the problem, not the feature list**

| **The problem** | **The module** |
| --- | --- |
| You cannot see what is happening | overlay layer |
| You react too slowly | assist layer |
| You want a different look | cosmetic layer |
| You keep re-tuning settings | utility / presets |
| The machine is flagged | identity layer, where the title supports it |

**Why this framing works**

People who start from the feature list enable everything, then cannot tell which
module is helping. People who start from a problem enable one thing, measure it,
and keep it only if it solved something.

**A worked example**

If you are losing fights because you do not know where the other player is, the
overlay is the answer and the assist layer is not. Adding assist on top of that
changes how your aim looks for no additional information gain. One module, one
problem.

**When to remove a module**

If you cannot describe what a module does for you in one sentence, it is costing
you performance and attention for nothing. Turn it off.

**The 80% case**

For most sessions, two modules enabled is the practical ceiling. Beyond that you
are paying frame time for capability you are not using.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
